# إيوان للمطابخ — موقع تعريفي

صفحة هبوط عربية (RTL) لشركة تفصيل وتصميم مطابخ، مبنية بـ HTML5 و Tailwind CSS (CDN) و JavaScript، وموجهة لجذب العملاء عبر الواتساب.

## التشغيل
افتح `index.html` مباشرة في المتصفح — لا يحتاج أي بناء.

## التخصيص السريع
- **رقم الواتساب:** غيّر `WHATSAPP_NUMBER` في أعلى السكربت داخل `index.html` (صيغة دولية بدون +، مثل `9665XXXXXXXX`).
- **مشاريع المعرض:** عدّل مصفوفة `projects` (العنوان، النمط `modern | classic | neoclassic`، المدينة، الصورة).
- **أسعار الحاسبة:** قيم `<option>` في قائمة الخامة = سعر المتر الطولي، و`data-factor` لكل نمط.
- **الألوان:** لوحة `wood` و `charcoal` و `ivory` في `tailwind.config`.

الصور حالياً من Unsplash كعناصر مؤقتة؛ استبدلها بصور مشاريعكم الفعلية. عند تعذّر تحميل أي صورة تظهر خلفية خشبية بديلة تلقائياً.
